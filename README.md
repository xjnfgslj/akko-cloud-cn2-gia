## 便宜 CN2 GIA 该看哪三件事

便宜是相对搬瓦工、DMIT 那类季度付近 50 美元的方案说的。CN2 GIA 的 IP transit 单 Mbps 成本在行业里被报到 120 美元这个量级，没有商家能把它卖成大白菜，所以真正要判断的不是“谁更便宜”，而是同样的钱买到了哪一段线路、多少流量、超了之后会怎样。

### 回程是不是三网都走 GIA

很多商家写“CN2 优化”，实际只有电信去回程走 GIA，联通移动走普通线路。晚高峰真正受压的是回程，三网回程全走 GIA 才算数。AkkoCloud 公开的说法是回程三网强制 GIA，去程电信联通走 GIA、移动走 CMIN2，这个组合在欧洲机房里算给得足。

有一点要提前知道：联通去程偶尔绕开 GIA，是这类产品的通病，不是某一家的问题。买之前用测试 IP 从自己的宽带跑一遍路由，比看任何宣传都准。

### 带宽给得高还是流量给得多

GIA 线路的成本压在带宽上，商家只能二选一：给你 500Mbps 峰值但每月限定几百 GB，或者给你不限流量但端口压到几十兆。AkkoCloud 两条线都做了，圣何塞是前者，年付 449 元给 800GB 和 1Gbps 端口；不限流量的机型放在 30Mbps、50Mbps 两档，价格直接跳到四位数月付。

### 超流量之后是限速还是停机

定量套餐超流后的处理方式写在服务条款里，限速到 1Mbps 至少还能连 SSH、网站还能打开，直接停机就要等下个账期。下单前花两分钟翻一下 ToS，比事后开工单省事。

## 什么情况下不该买 AkkoCloud

三种情况建议直接排除。

要亚洲低延迟节点的。AkkoCloud 只有圣何塞、法兰克福、伦敦三个机房，日本、香港、新加坡一个都没有。做面向国内用户的站，法兰克福 180ms 的物理延迟绕不过去，这不是线路优化能解决的。

要带宽突发的。500Mbps 和 1Gbps 的端口看着不小，但定量套餐的月流量卡在那里，跑超了要么加钱要么被限；真正不限流量的档位端口只有 30–50Mbps。

要中文工单秒回的。这家 2019 年开始做 CN2 GIA，运营时间不算短，但体量小，别指望有人 7×24 盯着工单。

## 几个买之前会问的问题

**联通去程到底走不走 GIA？** 官方说法是电信、联通去程走 CN2 GIA，移动去程走 CMIN2，回程三网强制 GIA。实测中联通去程偶有绕路，这是 CN2 GIA 产品的普遍现象。用自己的宽带跑一遍 traceroute 最可靠。

**有亚洲机房吗？** 没有。三个机房分别是美国圣何塞、德国法兰克福、英国伦敦。

**能支付宝付款吗？** 支持。

**延迟多少？** 法兰克福约 180ms，属于欧洲机房的正常水平；圣何塞更低，具体数值取决于你所在的城市和运营商，用测试 IP `45.9.10.146` 自己 ping 一遍。
